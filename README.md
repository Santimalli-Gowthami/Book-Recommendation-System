📚 Book Recommendation System

📖 Overview
This project recommends books using the K-Nearest Neighbors (KNN) machine learning algorithm. It analyzes book similarities based on user ratings and suggests books that are similar to a selected title.

🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

🚀 Features
- Book recommendation using KNN
- Data preprocessing
- Similar book suggestions
- Machine learning implementation

📂 Project File
- fcc_book_recommendation_knn.ipynb
